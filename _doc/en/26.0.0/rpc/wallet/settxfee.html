wallet

settxfee amount

Set the transaction fee rate in BTC/kvB for this wallet. Overrides the global -paytxfee command line parameter. Can be deactivated by passing 0 as the fee. In that case automatic fee selection will be used by default.

Arguments

#NameTypeRequiredDescription
1amountone ofyesThe transaction fee rate in BTC/kvB
  • option 1 (number)
  • option 2 (string)

Result

(boolean)

Examples

> bitcoin-cli settxfee 0.00001
> curl --user myusername --data-binary '{"jsonrpc": "1.0", "id": "curltest", "method": "settxfee", "params": [0.00001]}' -H 'content-type: text/plain;' http://127.0.0.1:8332/
