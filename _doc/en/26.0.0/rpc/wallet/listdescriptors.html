wallet

listdescriptors ( private )

List descriptors imported into a descriptor-enabled wallet.

Arguments

#NameTypeRequiredDescription
1privatebooleanno
default: false		Show private descriptors.

Result

(object)

  • wallet_name (string) Name of wallet this operation was performed on
  • descriptors (array) Array of descriptor objects (sorted by descriptor string representation)
    • each item (object)
      • desc (string) Descriptor string representation
      • timestamp (number) The creation time of the descriptor
      • active (boolean) Whether this descriptor is currently used to generate new addresses
      • internal (boolean, optional) True if this descriptor is used to generate change addresses. False if this descriptor is used to generate receiving addresses; defined only for active descriptors
      • range (array, optional) Defined only for ranged descriptors
        • [0] (number)
        • [1] (number)
      • next (number, optional) Same as next_index field. Kept for compatibility reason.
      • next_index (number, optional) The next index to generate addresses from; defined only for ranged descriptors

Examples

> bitcoin-cli listdescriptors 
> curl --user myusername --data-binary '{"jsonrpc": "1.0", "id": "curltest", "method": "listdescriptors", "params": []}' -H 'content-type: text/plain;' http://127.0.0.1:8332/
> bitcoin-cli listdescriptors true
> curl --user myusername --data-binary '{"jsonrpc": "1.0", "id": "curltest", "method": "listdescriptors", "params": [true]}' -H 'content-type: text/plain;' http://127.0.0.1:8332/
