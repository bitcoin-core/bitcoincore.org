network

getaddednodeinfo ( "node" )

Returns information about the given added node, or all added nodes (note that onetry addnodes are not listed here)

Arguments

#NameTypeRequiredDescription
1nodestringno
default: all nodes		If provided, return information about this specific node, otherwise all nodes are returned.

Result

(array)

  • each item (object)
    • addednode (string) The node IP address or name (as provided to addnode)
    • connected (boolean) If connected
    • addresses (array) Only when connected = true
      • each item (object)
        • address (string) The bitcoin server IP and port we're connected to
        • connected (string) connection, inbound or outbound

Examples

> bitcoin-cli getaddednodeinfo "192.168.0.201"
> curl --user myusername --data-binary '{"jsonrpc": "1.0", "id": "curltest", "method": "getaddednodeinfo", "params": ["192.168.0.201"]}' -H 'content-type: text/plain;' http://127.0.0.1:8332/
