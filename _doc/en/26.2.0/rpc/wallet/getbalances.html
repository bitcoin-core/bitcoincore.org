wallet

getbalances

Returns an object with all balances in BTC.

Arguments

None.

Result

(object)

  • mine (object) balances from outputs that the wallet can sign
    • trusted (string, amount) trusted balance (outputs created by the wallet or confirmed outputs)
    • untrusted_pending (string, amount) untrusted pending balance (outputs created by others that are in the mempool)
    • immature (string, amount) balance from immature coinbase outputs
    • used (string, amount, optional) (only present if avoid_reuse is set) balance from coins sent to addresses that were previously spent from (potentially privacy violating)
  • watchonly (object, optional) watchonly balances (not present if wallet does not watch anything)
    • trusted (string, amount) trusted balance (outputs created by the wallet or confirmed outputs)
    • untrusted_pending (string, amount) untrusted pending balance (outputs created by others that are in the mempool)
    • immature (string, amount) balance from immature coinbase outputs
  • lastprocessedblock (object) hash and height of the block this information was generated on
    • hash (string) hash of the block this information was generated on
    • height (number) height of the block this information was generated on
