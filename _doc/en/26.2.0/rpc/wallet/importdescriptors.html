wallet

importdescriptors requests

Import descriptors. This will trigger a rescan of the blockchain based on the earliest timestamp of all descriptors being imported. Requires a new wallet backup.

Note: This call can take over an hour to complete if using an early timestamp; during that time, other rpc calls may report that the imported keys, addresses or scripts exist but related transactions are still missing. The rescan is significantly faster if block filters are available (using startup option "-blockfilterindex=1").

Arguments

#NameTypeRequiredDescription
1requestsarrayyesData to be imported
  • each item (object)
    • desc (string) Descriptor to import.
    • active (boolean, optional, default=false) Set this descriptor to be the active descriptor for the corresponding output type/externality
    • range (one of, optional) If a ranged descriptor is used, this specifies the end or the range (in the form [begin,end]) to import
      • option 1 (number)
      • option 2 (array)
        • [0] (number)
        • [1] (number)
    • next_index (number, optional) If a ranged descriptor is set to active, this specifies the next index to generate addresses from
    • timestamp (one of) Time from which to start rescanning the blockchain for this descriptor, in UNIX epoch time
      Use the string "now" to substitute the current synced blockchain time.
      "now" can be specified to bypass scanning, for outputs which are known to never have been used, and
      0 can be specified to scan the entire blockchain. Blocks up to 2 hours before the earliest timestamp
      of all descriptors being imported will be scanned as well as the mempool.
      • option 1 (number)
      • option 2 (string)
    • internal (boolean, optional, default=false) Whether matching outputs should be treated as not incoming payments (e.g. change)
    • label (string, optional, default="") Label to assign to the address, only allowed with internal=false. Disabled for ranged descriptors

Result

(array)

  • each item (object)
    • success (boolean)
    • warnings (array, optional)
      • each item (string)
    • error (object, optional)
