--- name: getnewaddress btcversion: 26.2.0 btcgroup: wallet permalink: en/doc/26.2.0/rpc/wallet/getnewaddress/raw/ rawpage: true --- getnewaddress ( "label" ) ( "address_type" ) Returns a new Bitcoin address for receiving payments. If 'label' is specified, it is added to the address book so payments received with the address will be associated with 'label'. Arguments: 1. label (string, optional, default="") The label name for the address to be linked to. It can also be set to the empty string "" to represent the default label. The label does not need to exist, it will be created if there is no label by the given name. 2. address_type (string, optional, default: set by -addresstype) The address type to use. Options are "legacy", "p2sh-segwit", "bech32", and "bech32m". Result: (string)
