--- name: signmessage btcversion: 26.2.0 btcgroup: wallet permalink: en/doc/26.2.0/rpc/wallet/signmessage/raw/ rawpage: true --- signmessage "address" "message" Sign a message with the private key of an address Requires wallet passphrase to be set with walletpassphrase call if wallet is encrypted. Arguments: 1. address (string) The bitcoin address to use for the private key. 2. message (string) The message to create a signature of. Result: (string)
