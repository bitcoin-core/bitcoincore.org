--- name: restorewallet btcversion: 26.2.0 btcgroup: wallet permalink: en/doc/26.2.0/rpc/wallet/restorewallet/raw/ rawpage: true --- restorewallet "wallet_name" "backup_file" ( load_on_startup ) Restores and loads a wallet from backup. The rescan is significantly faster if a descriptor wallet is restored and block filters are available (using startup option "-blockfilterindex=1"). Arguments: 1. wallet_name (string) The name that will be applied to the restored wallet 2. backup_file (string) The backup file that will be used to restore the wallet. 3. load_on_startup (boolean, optional) Save wallet name to persistent settings and load on startup. True to add wallet to startup list, false to remove, null to leave unchanged. Result: (object) name (string) The wallet name if restored successfully. warnings (array, optional) Warning messages, if any, related to restoring and loading the wallet. each item (string)
