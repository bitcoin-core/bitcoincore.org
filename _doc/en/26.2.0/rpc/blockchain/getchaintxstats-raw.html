--- name: getchaintxstats btcversion: 26.2.0 btcgroup: blockchain permalink: en/doc/26.2.0/rpc/blockchain/getchaintxstats/raw/ rawpage: true --- getchaintxstats ( nblocks ) ( "blockhash" ) Compute statistics about the total number and rate of transactions in the chain. Arguments: 1. nblocks (number, optional, default: one month) Size of the window in number of blocks 2. blockhash (string, optional, default: chain tip) The hash of the block that ends the window. Result: (object) time (number, unix-time) The timestamp for the final block in the window, expressed in UNIX epoch time txcount (number) The total number of transactions in the chain up to that point window_final_block_hash (string) The hash of the final block in the window window_final_block_height (number) The height of the final block in the window. window_block_count (number) Size of the window in number of blocks window_tx_count (number, optional) The number of transactions in the window. Only returned if "window_block_count" is > 0 window_interval (number, optional) The elapsed time in the window in seconds. Only returned if "window_block_count" is > 0 txrate (number, optional) The average rate of transactions per second in the window. Only returned if "window_interval" is > 0
