--- name: getprioritisedtransactions btcversion: 26.2.0 btcgroup: mining permalink: en/doc/26.2.0/rpc/mining/getprioritisedtransactions/raw/ rawpage: true --- getprioritisedtransactions Returns a map of all user-created (see prioritisetransaction) fee deltas by txid, and whether the tx is present in mempool. Arguments: none Result: (object) ... (object) fee_delta (number) transaction fee delta in satoshis in_mempool (boolean) whether this transaction is currently in mempool
