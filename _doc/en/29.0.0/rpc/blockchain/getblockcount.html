blockchain

getblockcount

Returns the height of the most-work fully-validated chain. The genesis block has height 0.

Arguments

None.

Result

(number)

Examples

> bitcoin-cli getblockcount 
> curl --user myusername --data-binary '{"jsonrpc": "2.0", "id": "curltest", "method": "getblockcount", "params": []}' -H 'content-type: application/json' http://127.0.0.1:8332/
