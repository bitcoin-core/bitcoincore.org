wallet

unloadwallet ( "wallet_name" ) ( load_on_startup )

Unloads the wallet referenced by the request endpoint, otherwise unloads the wallet specified in the argument. Specifying the wallet name on a wallet endpoint is invalid.

Arguments

#NameTypeRequiredDescription
1wallet_namestringno
default: the wallet name from the RPC endpoint		The name of the wallet to unload. If provided both here and in the RPC endpoint, the two must be identical.
2load_on_startupbooleannoSave wallet name to persistent settings and load on startup. True to add wallet to startup list, false to remove, null to leave unchanged.

Result

(object)

  • warnings (array, optional) Warning messages, if any, related to unloading the wallet.
    • each item (string)

Examples

> bitcoin-cli unloadwallet wallet_name
> curl --user myusername --data-binary '{"jsonrpc": "2.0", "id": "curltest", "method": "unloadwallet", "params": [wallet_name]}' -H 'content-type: application/json' http://127.0.0.1:8332/
