wallet

walletprocesspsbt "psbt" ( sign ) ( "sighashtype" ) ( bip32derivs ) ( finalize )

Update a PSBT with input information from our wallet and then sign inputs that we can sign for. Requires wallet passphrase to be set with walletpassphrase call if wallet is encrypted.

Arguments

#NameTypeRequiredDescription
1psbtstringyesThe transaction base64 string
2signbooleanno
default: true		Also sign the transaction when updating (requires wallet to be unlocked)
3sighashtypestringno
default: "DEFAULT for Taproot, ALL otherwise"		The signature hash type to sign with if not specified by the PSBT. Must be one of
"DEFAULT"
"ALL"
"NONE"
"SINGLE"
"ALL|ANYONECANPAY"
"NONE|ANYONECANPAY"
"SINGLE|ANYONECANPAY"
4bip32derivsbooleanno
default: true		Include BIP 32 derivation paths for public keys if we know them
5finalizebooleanno
default: true		Also finalize inputs if possible

Result

(object)

  • psbt (string) The base64-encoded partially signed transaction
  • complete (boolean) If the transaction has a complete set of signatures
  • hex (string, optional) The hex-encoded network transaction if complete

Examples

> bitcoin-cli walletprocesspsbt "psbt"
