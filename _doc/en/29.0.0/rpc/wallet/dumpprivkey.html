wallet

dumpprivkey "address"

Reveals the private key corresponding to 'address'. Then the importprivkey can be used with this output Note: This command is only compatible with legacy wallets.

Arguments

#NameTypeRequiredDescription
1addressstringyesThe bitcoin address for the private key

Result

(string)

Examples

> bitcoin-cli dumpprivkey "myaddress"
> bitcoin-cli importprivkey "mykey"
> curl --user myusername --data-binary '{"jsonrpc": "2.0", "id": "curltest", "method": "dumpprivkey", "params": ["myaddress"]}' -H 'content-type: application/json' http://127.0.0.1:8332/
