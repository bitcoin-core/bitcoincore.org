wallet

getbalance ( "dummy" ) ( minconf ) ( include_watchonly ) ( avoid_reuse )

Returns the total available balance. The available balance is what the wallet considers currently spendable, and is thus affected by options which limit spendability such as -spendzeroconfchange.

Arguments

#NameTypeRequiredDescription
1dummy
positional placeholder		stringnoRemains for backward compatibility. Must be excluded or set to "*".
2minconfnumberno
default: 0		Only include transactions confirmed at least this many times.
3include_watchonlybooleanno
default: true for watch-only wallets, otherwise false		Also include balance in watch-only addresses (see 'importaddress')
4avoid_reusebooleanno
default: true		(only available if avoid_reuse wallet flag is set) Do not include balance in dirty outputs; addresses are considered dirty if they have previously been used in a transaction.

Result

(string, amount)

Examples

The total amount in the wallet with 0 or more confirmations
> bitcoin-cli getbalance 

The total amount in the wallet with at least 6 confirmations
> bitcoin-cli getbalance "*" 6

As a JSON-RPC call
> curl --user myusername --data-binary '{"jsonrpc": "2.0", "id": "curltest", "method": "getbalance", "params": ["*", 6]}' -H 'content-type: application/json' http://127.0.0.1:8332/
