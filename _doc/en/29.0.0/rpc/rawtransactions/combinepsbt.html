rawtransactions

combinepsbt txs

Combine multiple partially signed Bitcoin transactions into one transaction. Implements the Combiner role.

Arguments

#NameTypeRequiredDescription
1txsarrayyesThe base64 strings of partially signed transactions
  • each item (string)

Result

(string)

Examples

> bitcoin-cli combinepsbt '["mybase64_1", "mybase64_2", "mybase64_3"]'
