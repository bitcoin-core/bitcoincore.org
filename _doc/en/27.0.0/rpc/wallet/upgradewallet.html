wallet

upgradewallet ( version )

Upgrade the wallet. Upgrades to the latest version if no version number is specified. New keys may be generated and a new wallet backup will need to be made.

Arguments

#NameTypeRequiredDescription
1versionnumberno
default: 169900		The version number to upgrade to. Default is the latest wallet version.

Result

(object)

  • wallet_name (string) Name of wallet this operation was performed on
  • previous_version (number) Version of wallet before this operation
  • current_version (number) Version of wallet after this operation
  • result (string, optional) Description of result, if no error
  • error (string, optional) Error message (if there is one)

Examples

> bitcoin-cli upgradewallet 169900
> curl --user myusername --data-binary '{"jsonrpc": "1.0", "id": "curltest", "method": "upgradewallet", "params": [169900]}' -H 'content-type: text/plain;' http://127.0.0.1:8332/
