blockchain

gettxout "txid" n ( include_mempool )

Returns details about an unspent transaction output.

Arguments

#NameTypeRequiredDescription
1txidstringyesThe transaction id
2nnumberyesvout number
3include_mempoolbooleanno
default: true		Whether to include the mempool. Note that an unspent output that is spent in the mempool won't appear.

Result

(one of)

  • option 1 (null) If the UTXO was not found
  • option 2 (object) Otherwise
    • bestblock (string) The hash of the block at the tip of the chain
    • confirmations (number) The number of confirmations
    • value (string, amount) The transaction value in BTC
    • scriptPubKey (object)
      • asm (string) Disassembly of the public key script
      • desc (string) Inferred descriptor for the output
      • hex (string) The raw public key script bytes, hex-encoded
      • type (string) The type, eg pubkeyhash
      • address (string, optional) The Bitcoin address (only if a well-defined address exists)
    • coinbase (boolean) Coinbase or not

Examples

Get unspent transactions
> bitcoin-cli listunspent 

View the details
> bitcoin-cli gettxout "txid" 1

As a JSON-RPC call
> curl --user myusername --data-binary '{"jsonrpc": "1.0", "id": "curltest", "method": "gettxout", "params": ["txid", 1]}' -H 'content-type: text/plain;' http://127.0.0.1:8332/
