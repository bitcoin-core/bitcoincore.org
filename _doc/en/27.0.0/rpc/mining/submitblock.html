mining

submitblock "hexdata" ( "dummy" )

Attempts to submit new block to network. See https://en.bitcoin.it/wiki/BIP_0022 for full specification.

Arguments

#NameTypeRequiredDescription
1hexdatastringyesthe hex-encoded block data to submit
2dummy
positional placeholder		stringno
default: ignored		dummy value, for compatibility with BIP22. This value is ignored.

Result

(one of)

  • option 1 (null) If the block was accepted
  • option 2 (string) Otherwise

Examples

> bitcoin-cli submitblock "mydata"
> curl --user myusername --data-binary '{"jsonrpc": "1.0", "id": "curltest", "method": "submitblock", "params": ["mydata"]}' -H 'content-type: text/plain;' http://127.0.0.1:8332/
