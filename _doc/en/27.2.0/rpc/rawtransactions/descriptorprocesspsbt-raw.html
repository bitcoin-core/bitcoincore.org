--- name: descriptorprocesspsbt btcversion: 27.2.0 btcgroup: rawtransactions permalink: en/doc/27.2.0/rpc/rawtransactions/descriptorprocesspsbt/raw/ rawpage: true --- descriptorprocesspsbt "psbt" descriptors ( "sighashtype" ) ( bip32derivs ) ( finalize ) Update all segwit inputs in a PSBT with information from output descriptors, the UTXO set or the mempool. Then, sign the inputs we are able to with information from the output descriptors. Arguments: 1. psbt (string) The transaction base64 string 2. descriptors (array) An array of either strings or objects each item (one of) option 1: (string) option 2: (object) desc (string) An output descriptor range (one of, optional, default=1000) Up to what index HD chains should be explored (either end or [begin,end]) option 1: (number) option 2: (array) [0] (number) [1] (number) 3. sighashtype (string, optional, default="DEFAULT for Taproot, ALL otherwise") The signature hash type to sign with if not specified by the PSBT. Must be one of "DEFAULT" "ALL" "NONE" "SINGLE" "ALL|ANYONECANPAY" "NONE|ANYONECANPAY" "SINGLE|ANYONECANPAY" 4. bip32derivs (boolean, optional, default=true) Include BIP 32 derivation paths for public keys if we know them 5. finalize (boolean, optional, default=true) Also finalize inputs if possible Result: (object) psbt (string) The base64-encoded partially signed transaction complete (boolean) If the transaction has a complete set of signatures hex (string, optional) The hex-encoded network transaction if complete
