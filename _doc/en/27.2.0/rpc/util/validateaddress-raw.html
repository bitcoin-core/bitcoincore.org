--- name: validateaddress btcversion: 27.2.0 btcgroup: util permalink: en/doc/27.2.0/rpc/util/validateaddress/raw/ rawpage: true --- validateaddress "address" Return information about the given bitcoin address. Arguments: 1. address (string) The bitcoin address to validate Result: (object) isvalid (boolean) If the address is valid or not address (string, optional) The bitcoin address validated scriptPubKey (string, optional) The hex-encoded scriptPubKey generated by the address isscript (boolean, optional) If the key is a script iswitness (boolean, optional) If the address is a witness address witness_version (number, optional) The version number of the witness program witness_program (string, optional) The hex value of the witness program error (string, optional) Error message, if any error_locations (array, optional) Indices of likely error locations in address, if known (e.g. Bech32 errors) each item (number)
