--- name: verifymessage btcversion: 27.2.0 btcgroup: util permalink: en/doc/27.2.0/rpc/util/verifymessage/raw/ rawpage: true --- verifymessage "address" "signature" "message" Verify a signed message. Arguments: 1. address (string) The bitcoin address to use for the signature. 2. signature (string) The signature provided by the signer in base 64 encoding (see signmessage). 3. message (string) The message that was signed. Result: (boolean)
