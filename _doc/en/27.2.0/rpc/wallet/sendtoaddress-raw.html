--- name: sendtoaddress btcversion: 27.2.0 btcgroup: wallet permalink: en/doc/27.2.0/rpc/wallet/sendtoaddress/raw/ rawpage: true --- sendtoaddress "address" amount ( "comment" ) ( "comment_to" ) ( subtractfeefromamount ) ( replaceable ) ( conf_target ) ( "estimate_mode" ) ( avoid_reuse ) ( fee_rate ) ( verbose ) Send an amount to a given address. Requires wallet passphrase to be set with walletpassphrase call if wallet is encrypted. Arguments: 1. address (string) The bitcoin address to send to. 2. amount (one of) The amount in BTC to send. eg 0.1 option 1: (number) option 2: (string) 3. comment (string, optional) A comment used to store what the transaction is for. This is not part of the transaction, just kept in your wallet. 4. comment_to (string, optional) A comment to store the name of the person or organization to which you're sending the transaction. This is not part of the transaction, just kept in your wallet. 5. subtractfeefromamount (boolean, optional, default=false) The fee will be deducted from the amount being sent. The recipient will receive less bitcoins than you enter in the amount field. 6. replaceable (boolean, optional, default: wallet default) Signal that this transaction can be replaced by a transaction (BIP 125) 7. conf_target (number, optional, default: wallet -txconfirmtarget) Confirmation target in blocks 8. estimate_mode (string, optional, default="unset") The fee estimate mode, must be one of (case insensitive): "unset" "economical" "conservative" 9. avoid_reuse (boolean, optional, default=true) (only available if avoid_reuse wallet flag is set) Avoid spending from dirty addresses; addresses are considered dirty if they have previously been used in a transaction. If true, this also activates avoidpartialspends, grouping outputs by their addresses. 10. fee_rate (one of, optional, default: not set, fall back to wallet fee estimation) Specify a fee rate in sat/vB. option 1: (number) option 2: (string) 11. verbose (boolean, optional, default=false) If true, return extra information about the transaction. Result: (one of) option 1: (string) if verbose is not set or set to false option 2: (object) if verbose is set to true txid (string) The transaction id. fee_reason (string) The transaction fee reason.
