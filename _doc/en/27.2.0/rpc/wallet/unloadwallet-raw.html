--- name: unloadwallet btcversion: 27.2.0 btcgroup: wallet permalink: en/doc/27.2.0/rpc/wallet/unloadwallet/raw/ rawpage: true --- unloadwallet ( "wallet_name" ) ( load_on_startup ) Unloads the wallet referenced by the request endpoint, otherwise unloads the wallet specified in the argument. Specifying the wallet name on a wallet endpoint is invalid. Arguments: 1. wallet_name (string, optional, default: the wallet name from the RPC endpoint) The name of the wallet to unload. If provided both here and in the RPC endpoint, the two must be identical. 2. load_on_startup (boolean, optional) Save wallet name to persistent settings and load on startup. True to add wallet to startup list, false to remove, null to leave unchanged. Result: (object) warnings (array, optional) Warning messages, if any, related to unloading the wallet. each item (string)
