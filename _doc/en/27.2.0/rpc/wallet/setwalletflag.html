wallet

setwalletflag "flag" ( value )

Change the state of the given wallet flag for a wallet.

Arguments

#NameTypeRequiredDescription
1flagstringyesThe name of the flag to change. Current available flags: avoid_reuse
2valuebooleanno
default: true		The new state.

Result

(object)

  • flag_name (string) The name of the flag that was modified
  • flag_state (boolean) The new state of the flag
  • warnings (string, optional) Any warnings associated with the change
