--- name: dumpprivkey btcversion: 27.2.0 btcgroup: wallet permalink: en/doc/27.2.0/rpc/wallet/dumpprivkey/raw/ rawpage: true --- dumpprivkey "address" Reveals the private key corresponding to 'address'. Then the importprivkey can be used with this output Note: This command is only compatible with legacy wallets. Arguments: 1. address (string) The bitcoin address for the private key Result: (string)
