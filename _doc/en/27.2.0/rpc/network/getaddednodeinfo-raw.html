--- name: getaddednodeinfo btcversion: 27.2.0 btcgroup: network permalink: en/doc/27.2.0/rpc/network/getaddednodeinfo/raw/ rawpage: true --- getaddednodeinfo ( "node" ) Returns information about the given added node, or all added nodes (note that onetry addnodes are not listed here) Arguments: 1. node (string, optional, default: all nodes) If provided, return information about this specific node, otherwise all nodes are returned. Result: (array) each item (object) addednode (string) The node IP address or name (as provided to addnode) connected (boolean) If connected addresses (array) Only when connected = true each item (object) address (string) The bitcoin server IP and port we're connected to connected (string) connection, inbound or outbound
