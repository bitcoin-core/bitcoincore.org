--- name: joinpsbts btcversion: 31.0.0 btcgroup: rawtransactions permalink: en/doc/31.0.0/rpc/rawtransactions/joinpsbts/raw/ rawpage: true --- joinpsbts ["psbt",...] Joins multiple distinct PSBTs with different inputs and outputs into one PSBT with inputs and outputs from all of the PSBTs No input in any of the PSBTs can be in more than one of the PSBTs. Arguments: 1. txs (json array, required) The base64 strings of partially signed transactions [ "psbt", (string, required) A base64 string of a PSBT ... ] Result: "str" (string) The base64-encoded partially signed transaction Examples: > bitcoin-cli joinpsbts "psbt"
