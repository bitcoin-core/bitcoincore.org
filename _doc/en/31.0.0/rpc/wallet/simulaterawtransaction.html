wallet

simulaterawtransaction ( rawtxs ) ( options )

Calculate the balance change resulting in the signing and broadcasting of the given transaction(s).

Arguments

#NameTypeRequiredDescription
1rawtxsarraynoAn array of hex strings of raw transactions.
  • each item (string)
2options
fields may also be passed as named arguments		objectno
  • include_watchonly (boolean, optional, default=false) (DEPRECATED) No longer used

Result

(object)

  • balance_change (string, amount) The wallet balance change (negative means decrease).

Examples

> bitcoin-cli simulaterawtransaction ["myhex"]
> curl --user myusername --data-binary '{"jsonrpc": "2.0", "id": "curltest", "method": "simulaterawtransaction", "params": [["myhex"]]}' -H 'content-type: application/json' http://127.0.0.1:8332/
