blockchain

getmempoolcluster "txid"

Returns mempool data for given cluster

Arguments

#NameTypeRequiredDescription
1txidstringyesThe txid of a transaction in the cluster

Result

(object)

  • clusterweight (number) total sigops-adjusted weight (as defined in BIP 141 and modified by '-bytespersigop')
  • txcount (number) number of transactions
  • chunks (array) chunks in this cluster (in mining order)
    • each item (object)
      • chunkfee (number) fees of the transactions in this chunk
      • chunkweight (number) sigops-adjusted weight of all transactions in this chunk
      • txs (array) transactions in this chunk in mining order
        • each item (string)

Examples

> bitcoin-cli getmempoolcluster txid
> curl --user myusername --data-binary '{"jsonrpc": "2.0", "id": "curltest", "method": "getmempoolcluster", "params": [txid]}' -H 'content-type: application/json' http://127.0.0.1:8332/
