blockchain

getrawmempool ( verbose ) ( mempool_sequence )

Returns all transaction ids in memory pool as a json array of string transaction ids.

Hint: use getmempoolentry to fetch a specific transaction from the mempool.

Arguments

#NameTypeRequiredDescription
1verbosebooleanno
default: false		True for a json object, false for array of transaction ids
2mempool_sequencebooleanno
default: false		If verbose=false, returns a json object with transaction list and mempool sequence number attached.

Result

(one of)

  • option 1 (array) for verbose = false
    • each item (string)
  • option 2 (object) for verbose = true
    • … (object, optional)
      • vsize (number) virtual transaction size as defined in BIP 141. This is different from actual serialized size for witness transactions as witness data is discounted.
      • weight (number) transaction weight as defined in BIP 141.
      • time (number, unix-time) local time transaction entered pool in seconds since 1 Jan 1970 GMT
      • height (number) block height when transaction entered pool
      • descendantcount (number) number of in-mempool descendant transactions (including this one)
      • descendantsize (number) virtual transaction size of in-mempool descendants (including this one)
      • ancestorcount (number) number of in-mempool ancestor transactions (including this one)
      • ancestorsize (number) virtual transaction size of in-mempool ancestors (including this one)
      • chunkweight (number) sigops-adjusted weight (as defined in BIP 141 and modified by '-bytespersigop') of this transaction's chunk
      • wtxid (string) hash of serialized transaction, including witness data
      • fees (object)
        • base (string, amount) transaction fee, denominated in BTC
        • modified (string, amount) transaction fee with fee deltas used for mining priority, denominated in BTC
        • ancestor (string, amount) transaction fees of in-mempool ancestors (including this one) with fee deltas used for mining priority, denominated in BTC
        • descendant (string, amount) transaction fees of in-mempool descendants (including this one) with fee deltas used for mining priority, denominated in BTC
        • chunk (string, amount) transaction fees of chunk, denominated in BTC
      • depends (array) unconfirmed transactions used as inputs for this transaction
        • each item (string)
      • spentby (array) unconfirmed transactions spending outputs from this transaction
        • each item (string)
      • bip125-replaceable (boolean) Whether this transaction signals BIP125 replaceability or has an unconfirmed ancestor signaling BIP125 replaceability. (DEPRECATED)
      • unbroadcast (boolean) Whether this transaction is currently unbroadcast (initial broadcast not yet acknowledged by any peers)
  • option 3 (object) for verbose = false and mempool_sequence = true
    • txids (array)
      • each item (string)
    • mempool_sequence (number) The mempool sequence value.

Examples

> bitcoin-cli getrawmempool true
> curl --user myusername --data-binary '{"jsonrpc": "2.0", "id": "curltest", "method": "getrawmempool", "params": [true]}' -H 'content-type: application/json' http://127.0.0.1:8332/
