--- name: joinpsbts btcversion: 32.0.0 btcgroup: rawtransactions permalink: en/doc/32.0.0/rpc/rawtransactions/joinpsbts/ --- joinpsbts ["psbt",...] Joins multiple distinct version 0 PSBTs with different inputs and outputs into one version 0 PSBT with inputs and outputs from all of the PSBTs No input in any of the PSBTs can be in more than one of the PSBTs. Arguments: 1. txs (json array, required) The base64 strings of partially signed transactions [ "psbt", (string, required) A base64 string of a PSBT ... ] Result: "str" (string) The base64-encoded partially signed transaction Examples: > bitcoin-cli joinpsbts "psbt"
