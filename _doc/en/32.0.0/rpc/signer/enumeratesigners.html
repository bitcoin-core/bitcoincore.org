--- name: enumeratesigners btcversion: 32.0.0 btcgroup: signer permalink: en/doc/32.0.0/rpc/signer/enumeratesigners/ --- enumeratesigners Returns a list of external signers from -signer. Signers with duplicate master key fingerprints are skipped. Result: { (json object) "signers" : [ (json array) { (json object) "fingerprint" : "hex", (string) Master key fingerprint "name" : "str" (string) Device name, the model returned by the signer }, ... ] } Examples: > bitcoin-cli enumeratesigners > curl --user myusername --data-binary '{"jsonrpc": "2.0", "id": "curltest", "method": "enumeratesigners", "params": []}' -H 'content-type: application/json' http://127.0.0.1:8332/
