wallet

getrawchangeaddress ( "address_type" )

Returns a new Bitcoin address, for receiving change. This is for use with raw transactions, NOT normal use.

Arguments

#NameTypeRequiredDescription
1address_typestringno
default: set by -changetype		The address type to use. Options are "legacy", "p2sh-segwit", "bech32", "bech32m".

Result

(string)

Examples

> bitcoin-cli getrawchangeaddress 
> curl --user myusername --data-binary '{"jsonrpc": "2.0", "id": "curltest", "method": "getrawchangeaddress", "params": []}' -H 'content-type: application/json' http://127.0.0.1:8332/
