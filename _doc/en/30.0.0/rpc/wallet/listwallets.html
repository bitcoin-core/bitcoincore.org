wallet

listwallets

Returns a list of currently loaded wallets. For full information on the wallet, use "getwalletinfo"

Arguments

None.

Result

(array)

  • each item (string)

Examples

> bitcoin-cli listwallets 
> curl --user myusername --data-binary '{"jsonrpc": "2.0", "id": "curltest", "method": "listwallets", "params": []}' -H 'content-type: application/json' http://127.0.0.1:8332/
