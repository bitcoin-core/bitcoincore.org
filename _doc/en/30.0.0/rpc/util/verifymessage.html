util

verifymessage "address" "signature" "message"

Verify a signed message.

Arguments

#NameTypeRequiredDescription
1addressstringyesThe bitcoin address to use for the signature.
2signaturestringyesThe signature provided by the signer in base 64 encoding (see signmessage).
3messagestringyesThe message that was signed.

Result

(boolean)

Examples

Unlock the wallet for 30 seconds
> bitcoin-cli walletpassphrase "mypassphrase" 30

Create the signature
> bitcoin-cli signmessage "1D1ZrZNe3JUo7ZycKEYQQiQAWd9y54F4XX" "my message"

Verify the signature
> bitcoin-cli verifymessage "1D1ZrZNe3JUo7ZycKEYQQiQAWd9y54F4XX" "signature" "my message"

As a JSON-RPC call
> curl --user myusername --data-binary '{"jsonrpc": "2.0", "id": "curltest", "method": "verifymessage", "params": ["1D1ZrZNe3JUo7ZycKEYQQiQAWd9y54F4XX", "signature", "my message"]}' -H 'content-type: application/json' http://127.0.0.1:8332/
