rawtransactions

descriptorprocesspsbt "psbt" descriptors ( "sighashtype" ) ( bip32derivs ) ( finalize )

Update all segwit inputs in a PSBT with information from output descriptors, the UTXO set or the mempool. Then, sign the inputs we are able to with information from the output descriptors.

    • option 2 (object)

      • range (one of, optional, default=1000) Up to what index HD chains should be explored (either end or [begin,end])
        • option 1 (number)
        • option 2 (array)

          • [1] (number)
