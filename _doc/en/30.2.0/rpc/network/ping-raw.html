--- name: ping btcversion: 30.2.0 btcgroup: network permalink: en/doc/30.2.0/rpc/network/ping/raw/ rawpage: true --- ping Requests that a ping be sent to all other nodes, to measure ping time. Results are provided in getpeerinfo. Ping command is handled in queue with all other commands, so it measures processing backlog, not just network ping. Arguments: none Result: (null)
