blockchain

waitfornewblock ( timeout ) ( "current_tip" )

Waits for any new block and returns useful info about it.

Returns the current block on timeout or exit.

Make sure to use no RPC timeout (bitcoin-cli -rpcclienttimeout=0)

Arguments

#NameTypeRequiredDescription
1timeoutnumberno
default: 0		Time in milliseconds to wait for a response. 0 indicates no timeout.
2current_tipstringnoMethod waits for the chain tip to differ from this.

Result

(object)

  • hash (string) The blockhash
  • height (number) Block height
