wallet

listlockunspent

Returns list of temporarily unspendable outputs. See the lockunspent call to lock and unlock transactions for spending.

Arguments

None.

Result

(array)

  • each item (object)
    • txid (string) The transaction id locked
    • vout (number) The vout value
