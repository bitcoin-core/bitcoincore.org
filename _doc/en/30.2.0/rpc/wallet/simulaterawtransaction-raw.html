--- name: simulaterawtransaction btcversion: 30.2.0 btcgroup: wallet permalink: en/doc/30.2.0/rpc/wallet/simulaterawtransaction/raw/ rawpage: true --- simulaterawtransaction ( rawtxs ) ( options ) Calculate the balance change resulting in the signing and broadcasting of the given transaction(s). Arguments: 1. rawtxs (array, optional) An array of hex strings of raw transactions. each item (string) 2. options (object, optional) include_watchonly (boolean, optional, default=false) (DEPRECATED) No longer used Result: (object) balance_change (string, amount) The wallet balance change (negative means decrease).
