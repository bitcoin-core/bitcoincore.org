--- name: walletlock btcversion: 30.2.0 btcgroup: wallet permalink: en/doc/30.2.0/rpc/wallet/walletlock/raw/ rawpage: true --- walletlock Removes the wallet encryption key from memory, locking the wallet. After calling this method, you will need to call walletpassphrase again before being able to call any methods which require the wallet to be unlocked. Arguments: none Result: (null)
