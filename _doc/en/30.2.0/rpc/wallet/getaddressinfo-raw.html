--- name: getaddressinfo btcversion: 30.2.0 btcgroup: wallet permalink: en/doc/30.2.0/rpc/wallet/getaddressinfo/raw/ rawpage: true --- getaddressinfo "address" Return information about the given bitcoin address. Some of the information will only be present if the address is in the active wallet. Arguments: 1. address (string) The bitcoin address for which to get information. Result: (object) address (string) The bitcoin address validated. scriptPubKey (string) The hex-encoded output script generated by the address. ismine (boolean) If the address is yours. iswatchonly (boolean) (DEPRECATED) Always false. solvable (boolean) If we know how to spend coins sent to this address, ignoring the possible lack of private keys. desc (string, optional) A descriptor for spending coins sent to this address (only when solvable). parent_desc (string, optional) The descriptor used to derive this address if this is a descriptor wallet isscript (boolean, optional) If the key is a script. ischange (boolean) If the address was used for change output. iswitness (boolean) If the address is a witness address. witness_version (number, optional) The version number of the witness program. witness_program (string, optional) The hex value of the witness program. script (string, optional) The output script type. Only if isscript is true and the redeemscript is known. Possible types: nonstandard, pubkey, pubkeyhash, scripthash, multisig, nulldata, witness_v0_keyhash, witness_v0_scripthash, witness_unknown. hex (string, optional) The redeemscript for the p2sh address. pubkeys (array, optional) Array of pubkeys associated with the known redeemscript (only if script is multisig). each item (string) sigsrequired (number, optional) The number of signatures required to spend multisig output (only if script is multisig). pubkey (string, optional) The hex value of the raw public key for single-key addresses (possibly embedded in P2SH or P2WSH). embedded (object, optional) Information about the address embedded in P2SH or P2WSH, if relevant and known. iscompressed (boolean, optional) If the pubkey is compressed. timestamp (number, unix-time, optional) The creation time of the key, if available, expressed in UNIX epoch time. hdkeypath (string, optional) The HD keypath, if the key is HD and available. hdseedid (string, optional) The Hash160 of the HD seed. hdmasterfingerprint (string, optional) The fingerprint of the master key. labels (array) Array of labels associated with the address. Currently limited to one label but returned as an array to keep the API stable if multiple labels are enabled in the future. each item (string)
