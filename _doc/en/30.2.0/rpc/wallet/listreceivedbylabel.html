wallet

listreceivedbylabel ( minconf ) ( include_empty ) ( include_watchonly ) ( include_immature_coinbase )

List received transactions by label.

Arguments

#NameTypeRequiredDescription
1minconfnumberno
default: 1		The minimum number of confirmations before payments are included.
2include_emptybooleanno
default: false		Whether to include labels that haven't received any payments.
3include_watchonlybooleanno
default: false		(DEPRECATED) No longer used
4include_immature_coinbasebooleanno
default: false		Include immature coinbase transactions.

Result

(array)

  • each item (object)
    • amount (string, amount) The total amount received by addresses with this label
    • confirmations (number) The number of confirmations of the most recent transaction included
    • label (string) The label of the receiving address. The default label is ""
