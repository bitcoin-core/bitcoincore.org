mining

getprioritisedtransactions

Returns a map of all user-created (see prioritisetransaction) fee deltas by txid, and whether the tx is present in mempool.

Arguments

None.

Result

(object)

  • … (object, optional)
    • fee_delta (number) transaction fee delta in satoshis
    • in_mempool (boolean) whether this transaction is currently in mempool
    • modified_fee (number, optional) modified fee in satoshis. Only returned if in_mempool=true
