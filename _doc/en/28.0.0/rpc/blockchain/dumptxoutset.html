blockchain

dumptxoutset "path"

Write the serialized UTXO set to a file.

Arguments

#NameTypeRequiredDescription
1pathstringyesPath to the output file. If relative, will be prefixed by datadir.

Result

(object)

  • coins_written (number) the number of coins written in the snapshot
  • base_hash (string) the hash of the base of the snapshot
  • base_height (number) the height of the base of the snapshot
  • path (string) the absolute path that the snapshot was written to
  • txoutset_hash (string) the hash of the UTXO set contents
  • nchaintx (number) the number of transactions in the chain up to and including the base block

Examples

> bitcoin-cli dumptxoutset utxo.dat
