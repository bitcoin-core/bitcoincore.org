mining

getmininginfo

Returns a json object containing mining-related information.

Arguments

None.

Result

(object)

  • blocks (number) The current block
  • currentblockweight (number, optional) The block weight of the last assembled block (only present if a block was ever assembled)
  • currentblocktx (number, optional) The number of block transactions of the last assembled block (only present if a block was ever assembled)
  • difficulty (number) The current difficulty
  • networkhashps (number) The network hashes per second
  • pooledtx (number) The size of the mempool
  • chain (string) current network name (main, test, testnet4, signet, regtest)
  • warnings (array) any network and blockchain warnings (run with `-deprecatedrpc=warnings` to return the latest warning as a single string)
    • each item (string)

Examples

> bitcoin-cli getmininginfo 
> curl --user myusername --data-binary '{"jsonrpc": "2.0", "id": "curltest", "method": "getmininginfo", "params": []}' -H 'content-type: application/json' http://127.0.0.1:8332/
