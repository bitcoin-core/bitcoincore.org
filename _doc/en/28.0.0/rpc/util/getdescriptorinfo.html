util

getdescriptorinfo "descriptor"

Analyses a descriptor.

Arguments

#NameTypeRequiredDescription
1descriptorstringyesThe descriptor.

Result

(object)

  • descriptor (string) The descriptor in canonical form, without private keys
  • checksum (string) The checksum for the input descriptor
  • isrange (boolean) Whether the descriptor is ranged
  • issolvable (boolean) Whether the descriptor is solvable
  • hasprivatekeys (boolean) Whether the input descriptor contained at least one private key

Examples

Analyse a descriptor
> bitcoin-cli getdescriptorinfo "wpkh([d34db33f/84h/0h/0h]0279be667ef9dcbbac55a06295Ce870b07029Bfcdb2dce28d959f2815b16f81798)"
