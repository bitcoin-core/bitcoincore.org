wallet

sendtoaddress "address" amount ( "comment" ) ( "comment_to" ) ( subtractfeefromamount ) ( replaceable ) ( conf_target ) ( "estimate_mode" ) ( avoid_reuse ) ( fee_rate ) ( verbose )

Send an amount to a given address. Requires wallet passphrase to be set with walletpassphrase call if wallet is encrypted.

Arguments

#NameTypeRequiredDescription
1addressstringyesThe bitcoin address to send to.
2amountone ofyesThe amount in BTC to send. eg 0.1
  • option 1 (number)
  • option 2 (string)
3commentstringnoA comment used to store what the transaction is for.
This is not part of the transaction, just kept in your wallet.
4comment_tostringnoA comment to store the name of the person or organization
to which you're sending the transaction. This is not part of the
transaction, just kept in your wallet.
5subtractfeefromamountbooleanno
default: false		The fee will be deducted from the amount being sent.
The recipient will receive less bitcoins than you enter in the amount field.
6replaceablebooleanno
default: wallet default		Signal that this transaction can be replaced by a transaction (BIP 125)
7conf_targetnumberno
default: wallet -txconfirmtarget		Confirmation target in blocks
8estimate_modestringno
default: "unset"		The fee estimate mode, must be one of (case insensitive):
unset, economical, conservative
unset means no mode set (economical mode is used if the transaction is replaceable;
otherwise, conservative mode is used).
economical estimates use a shorter time horizon, making them more
responsive to short-term drops in the prevailing fee market. This mode
potentially returns a lower fee rate estimate.
conservative estimates use a longer time horizon, making them
less responsive to short-term drops in the prevailing fee market. This mode
potentially returns a higher fee rate estimate.
9avoid_reusebooleanno
default: true		(only available if avoid_reuse wallet flag is set) Avoid spending from dirty addresses; addresses are considered
dirty if they have previously been used in a transaction. If true, this also activates avoidpartialspends, grouping outputs by their addresses.
10fee_rateone ofno
default: not set, fall back to wallet fee estimation		Specify a fee rate in sat/vB.
  • option 1 (number)
  • option 2 (string)
11verbosebooleanno
default: false		If true, return extra information about the transaction.

Result

(one of)

  • option 1 (string) if verbose is not set or set to false
  • option 2 (object) if verbose is set to true
    • txid (string) The transaction id.
    • fee_reason (string) The transaction fee reason.
