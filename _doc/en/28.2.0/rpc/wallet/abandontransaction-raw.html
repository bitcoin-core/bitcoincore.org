--- name: abandontransaction btcversion: 28.2.0 btcgroup: wallet permalink: en/doc/28.2.0/rpc/wallet/abandontransaction/raw/ rawpage: true --- abandontransaction "txid" Mark in-wallet transaction as abandoned This will mark this transaction and all its in-wallet descendants as abandoned which will allow for their inputs to be respent. It can be used to replace "stuck" or evicted transactions. It only works on transactions which are not included in a block and are not currently in the mempool. It has no effect on transactions which are already abandoned. Arguments: 1. txid (string) The transaction id Result: (null)
