wallet

signmessage "address" "message"

Sign a message with the private key of an address Requires wallet passphrase to be set with walletpassphrase call if wallet is encrypted.

Arguments

#NameTypeRequiredDescription
1addressstringyesThe bitcoin address to use for the private key.
2messagestringyesThe message to create a signature of.

Result

(string)
