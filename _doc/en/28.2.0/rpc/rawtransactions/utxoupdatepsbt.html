rawtransactions

utxoupdatepsbt "psbt" ( descriptors )

Updates all segwit inputs and outputs in a PSBT with data from output descriptors, the UTXO set, txindex, or the mempool.

Arguments

#NameTypeRequiredDescription
1psbtstringyesA base64 string of a PSBT
2descriptorsarraynoAn array of either strings or objects
  • each item (one of)
    • option 1 (string)
    • option 2 (object)
      • desc (string) An output descriptor
      • range (one of, optional, default=1000) Up to what index HD chains should be explored (either end or [begin,end])
        • option 1 (number)
        • option 2 (array)
          • [0] (number)
          • [1] (number)

Result

(string)
