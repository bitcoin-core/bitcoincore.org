--- name: verifychain btcversion: 28.2.0 btcgroup: blockchain permalink: en/doc/28.2.0/rpc/blockchain/verifychain/raw/ rawpage: true --- verifychain ( checklevel ) ( nblocks ) Verifies blockchain database. Arguments: 1. checklevel (number, optional, default: 3, range=0-4) How thorough the block verification is: - level 0 reads the blocks from disk - level 1 verifies block validity - level 2 verifies undo data - level 3 checks disconnection of tip blocks - level 4 tries to reconnect the blocks - each level includes the checks of the previous levels 2. nblocks (number, optional, default: 6, 0=all) The number of blocks to check. Result: (boolean)
